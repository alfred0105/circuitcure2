포함된 분류 그룹

    탐지 결과

    핀 표시: 초록은 이미지에서 찾은 패드 후보, 노랑은 2/3단자 소자 박스에서 추정했지만 확인되지 않은 위치, 자홍은 패드 후보와 일치한 위치입니다. IC는 보이는 가장자리 패드 행이 대칭·균일할 때만 표시합니다.
    기본 규칙: 저항·커패시터·인덕터·다이오드·LED·퓨즈 등은 2단자, 트랜지스터·포텐셔미터·전압 레귤레이터는 3단자 후보로 봅니다. 릴레이·스위치·커넥터·IC처럼 배열이 달라지는 소자는 이미지에서 고른 패드 행을 찾은 경우에만 표시합니다.
    샘플을 선택하거나 이미지를 업로드한 뒤 탐지 실행을 누르세요.

    탐지 박스 검수

    이미지에서 박스를 눌러 선택하고, 드래그해 위치를 옮기세요. 박스 추가 모드에서 드래그하면 새 박스를 그립니다. 표에서 종류·좌표를 직접 고치거나 후보 사용을 끌 수 있습니다.

    핀 후보는 소자 종류에 따라 2개·3개 단자 배열을 적용합니다. IC·커넥터 등 핀 수가 달라지는 부품은 관측된 패드 행이 균일할 때만 후보를 표시합니다. 노란 위치는 저신뢰도 추정이며 실제 핀 확정이 아닙니다.

    정답 라벨로 직접 평가

    이미지(또는 샘플)와 YOLO 형식 정답 라벨(.txt)을 넣어 위치 탐지 성능을 계산합니다. 클래스 이름은 라벨별 위치 재현율을 나누어 볼 때만 사용합니다.

    조합은 confidence 순으로 박스를 합친 뒤 IoU 0.50 class-agnostic NMS로 중복을 정리합니다. 외부 모델은 첫 실행 때 불러옵니다.
    한 줄마다 class_id x_center y_center width height, 좌표는 이미지 크기 기준 0~1 정규화 값이어야 합니다.
    라벨별 위치 재현율을 보려면 class_id 순서대로 입력합니다. 숫자 ID의 의미를 모르면 비워도 전체 위치 점수는 계산됩니다.
    예: 여러 세부 라벨을 하나의 집계 이름으로 묶을 때 씁니다. 예측 소자 종류가 맞는지는 검사하지 않습니다.
    박스 IoU 0.50, 현재 신뢰도 임계값과 추론 모드 설정을 사용합니다.

    YOLO 데이터셋 ZIP 일괄 평가

    이미지와 같은 이름의 YOLO 라벨 파일이 들어 있는 ZIP을 올리면 라벨이 있는 이미지 최대 1,000장을 한 번에 평가합니다. `images/`와 `labels/` 폴더 구조를 지원합니다.

    ZIP 최대 40 MB, 압축 해제 후 최대 500 MB. 라벨 파일이 없는 이미지는 평가에서 제외됩니다.
    모델과 라벨 이름 설정은 위 선택을 사용합니다.
    점수 계산 기준
    예측 클래스는 무시하고 위치만 비교합니다. 예측 박스 중심이 정답 소자 박스 안에 없으면 채점에서 제외합니다. 정답 영역 안의 예측은 IoU ≥ 0.50으로 1:1 매칭해 TP/FP/FN을 계산합니다. 라벨별로는 위치 재현율만 제공하며, 이 지표는 클래스 정확도나 전체 이미지 표준 mAP와 다릅니다.
